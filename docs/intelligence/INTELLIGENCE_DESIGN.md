# Intelligence design

The hybrid system shares confirmed session answers across guided discovery, conversation, Canvas and Analysis. Pure domain modules build context, rank useful gaps, evaluate readiness, retrieve approved references and produce proportionate catalogue directions. These operations do not require model calls.

`context-extraction.ts` implements limited auditable language rules for local mode. It can recognize explicit activity, channels/tools, portfolio/booking/invoice/content objectives, application requests and simplicity/budget constraints. It rejects obvious hypothetical phrasing and distinguishes website absence from absence of all channels. Derived signals stay labelled as possibilities; raw descriptions and confirmed preferences retain their provenance. Local mode is labelled deterministic guidance, not unrestricted language understanding.

The Cloudflare REST adapter remains behind `AiProvider`. Its system contract includes choice IDs, catalogue capabilities, current answers and the adaptive question/readiness. It requests concise structured candidates and useful alternatives, recognizes corrections and existing systems, and prohibits privileged operations or claims of completed work. Candidate fields/options/types and duplicate keys are validated for every provider with Zod plus question rules. Candidates remain unconfirmed evidence. A model cannot approve cases, modify prices, publish, execute tools or directly change answers.

Only explicitly enabled founder chat/alternative requests route remotely: `AI_PROVIDER=cloudflare`, `AI_ALLOW_REMOTE=true`, account ID and token are all required. Guided selections have no inference cost. Guests and simulations force local mode. Credentials stay server-side. HTTP timeouts, rate limits, malformed responses and validation failures return a safe local fallback without retries. PostgreSQL advisory-lock reservations bound calls per session/day and requested output tokens; failed attempts consume reservations.

These protections are call allowances, **not monetary or free-tier billing guarantees**. Nothing activates provider billing. Future paid inference needs account-level controls, per-model pricing, actual input/output usage, monetary reservations and reconciliation. Existing opt-in and limits were not weakened.

Assessment recommendations depend on actual descriptions, workflow evidence and explicit constraints, not industry alone. Existing providers are improved/integrated before replacing them; portfolios do not trigger AI; unfamiliar operations receive exploratory feasibility/specialist review. Manual templates and existing tools remain alternatives to custom/AI engineering. Missing pricing inputs stay manual review. Report snapshots preserve both supporting descriptions and uncertainties.

Current verification: controlled mocked HTTP tests cover contract shape, malformed output, invalid/duplicate fields, failure, timeout and 429 handling. Local configuration has no Cloudflare credentials and remote use is disabled, so **live inference remains unverified**. Confirmation gates remain necessary for hallucination protection; there is no independent factual verification service or AI-generated question planner.
