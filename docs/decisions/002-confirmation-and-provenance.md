# ADR 002: Confirmation and provenance before inference

Status: accepted, 2026-10-13.

Model JSON can be wrong and simulations are not client outcomes. Validate proposals and require explicit confirmation to change answers. Track source independently from approval. Only approved reference patterns are retrieved; current user facts determine recommendations. Reports are immutable revision snapshots, with draft/estimate/synthetic statuses carried to PDFs. Tradeoff: more explicit review steps, in exchange for inspectable evidence and no silent factual overrides.
