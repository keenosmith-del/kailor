# ADR 006 — independent sufficiency and explicit corrections

Status: accepted. Date: 2026-10-14.

## Context

Nonempty fields, skipped answers and generated recommendation counts cannot establish useful discovery. Repeated vague input can exhaust a question catalogue. Later corrections can contradict prose-derived facts while historical reports must remain immutable.

## Decision

Use a deterministic quality layer at mutation and extraction boundaries. Preserve uncertain input with explicit states while excluding it from useful facts. A standalone evidence policy establishes source-backed directions, limitations and material conflicts; readiness and recommendations both consume it, avoiding recommendation-count circularity. Persist simple completion/recovery states in the revision-scoped plan.

Keep conversational proposals pending. Persist guided material conflicts as pending without silently replacing confirmed facts. Explicit confirmation records resolved facets and revision, retires conflicting active evidence and preserves history. Apply current facets before reasoning and retain original quotes in source provenance. Historical or hypothetical statements do not define current status.

Block normal assessments when insufficient and retain failed simulations without reports/cases. Approved references refine investigation only; they cannot manufacture missing session evidence. Provider JSON must pass grounding and quality checks in addition to schema validation. Sensitive heuristics route locally before remote budget reservation.

## Consequences

All views agree on current eligibility and users have bounded recovery paths. Confirmation means user acceptance, not independent verification. Deterministic English clause rules and conservative private-data screening have limited coverage; semantic model replies still require stronger future evaluation. New optional provenance/state columns preserve historical data. Revision changes make existing snapshots stale without modifying them. No state-machine library, embeddings or new architecture service is required.
